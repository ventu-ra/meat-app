# Meat Backend with Spring

Backend desenvolvido em **Spring Boot 3.5.5** com **PostgreSQL**.

## Tecnologias

- Java 21
- Spring Boot (Web, Data JPA, Actuator, DevTools, Docker Compose)
- PostgreSQL
- Swagger (springdoc-openapi)

## Requisitos
- Java 21+
- Docker e Docker Compose
- Maven (ou `./mvnw`)

## Rodar
```bash
./mvnw spring-boot:run
```

## Rodar

- Restaurant: http://localhost:8080/api/v1/restaurant
- Swagger: http://localhost:8080/swagger-ui.html
